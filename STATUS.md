# Отчёт о ночной работе (3 октября 2026)

## Что сделано
- **WristPlayer**: приложение для iPhone со встроенным приложением для Apple Watch (SwiftUI, XcodeGen, iOS 18+ / watchOS 11+, работает на 27-х версиях).
- **iPhone**: импорт песен (кнопка «+», «Поделиться», папка в «Файлах», Apple Devices/iTunes на Windows), теги и обложки, поиск и сортировка, прослушивание на телефоне, тумблер «на часах» у каждой песни, прогресс передачи, место на часах, справка.
- **Синхронизация** (WatchConnectivity): манифест → часы удаляют лишнее, `transferFile` передаёт файлы в фоне, часы отчитываются инвентарём, WAV/AIFF/FLAC перед отправкой перекодируются в AAC, удаление песни на часах снимает отметку на телефоне.
- **Apple Watch**: список песен, «Исполняется», перемешивание, повтор, громкость колёсиком, фоновое воспроизведение через Bluetooth-наушники, управление из системного «Исполняется», продолжение с того же места, экспериментальный режим «Динамик часов».
- **CI**: приватный репозиторий <https://github.com/abc1113def/wrist-player>; GitHub Actions (macOS 26, Xcode 26.6) собирает оба приложения и гоняет тесты.
- **TestFlight**: workflow `TestFlight` (запуск вручную); заработает, когда будут добавлены секреты — см. [docs/INSTALL.md](docs/INSTALL.md).

## Что осталось
1. Посмотреть результат запуска 37071925575: скриншоты (не обрезается ли «Исполняется» на 40-мм часах) и сквозной тест.
2. Выбрать способ установки — [docs/INSTALL.md](docs/INSTALL.md). Рекомендую **TestFlight** ($99/год, Mac не нужен).
   Mac 2012 официально не потянет (максимум Xcode 12); можно попробовать через OpenCore Legacy Patcher + Xcode 26.
3. Проверить на устройствах: передачу больших файлов, звук через AirPods, работу в фоне.
4. Минуты macOS у приватного репозитория ограничены (около 200 в месяц). Если они закончатся, по твоему разрешению репозиторий можно сделать публичным: **Settings → Change visibility**.
