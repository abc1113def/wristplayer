# Статус WristPlayer (3 октября 2026, вечер)

## Что готово
- Приложение для iPhone и встроенное приложение для Apple Watch (SwiftUI, XcodeGen; iOS 18+ / watchOS 11+, работает и на 27-х версиях).
- iPhone: импорт песен («+», «Поделиться», папка в «Файлах», Apple Devices/iTunes на Windows), теги и обложки, поиск, сортировка, прослушивание, тумблер «на часах», прогресс передачи, место на часах.
- Синхронизация через WatchConnectivity: манифест → часы, файлы через `transferFile` в фоне, инвентарь ← часы, WAV/AIFF/FLAC → AAC.
- Часы: список, «Исполняется», перемешивание, повтор, громкость колёсиком, фон через Bluetooth-наушники, системное «Исполняется», продолжение с места.
- CI на GitHub Actions: сборка, 27 unit-тестов, скриншоты в симуляторах, конвейер TestFlight, скрипт установки с Mac (`scripts/mac-install.sh`).

## Что проверено
- ✅ Оба приложения собираются без ошибок и предупреждений; 27 тестов проходят (последний запуск 37144269846).
- ✅ Скриншоты iPhone (светлая и тёмная тема) и часов 46 мм и 40 мм: всё помещается.
- ⚠️ Сквозной тест «iPhone → часы» на паре симуляторов не проходит: в симуляторах WatchConnectivity
  не завершает подключение (известная нестабильность симуляторов). До передачи файлов дело не доходит,
  поэтому сама передача пока не проверена. Проверить её надёжно можно только на реальных устройствах.
- ❌ На реальных устройствах не проверялось.

## Установка — что выяснил
- Sideloadly, AltStore и xtool с Windows ставят только iPhone-часть: приложение для часов они не подписывают.
- Рабочие пути описаны в [docs/INSTALL.md](docs/INSTALL.md):
  - **TestFlight** — $99/год, Mac не нужен, всё уже настроено, нужно только добавить ключи;
  - **старый Mac** — через OpenCore Legacy Patcher и Xcode 26, затем `bash scripts/mac-install.sh`;
    нужна модель Mac: меню  → «Об этом Mac».

## Ждёт решения
- **Публикация репозитория.** В истории коммитов виден личный адрес почты. Заменить его на анонимный
  адрес GitHub (переписать историю) мне не разрешили. Варианты: разрешить это, публиковать как есть или
  оставить репозиторий приватным.
- **Способ установки:** TestFlight или старый Mac (и какая у него модель).
