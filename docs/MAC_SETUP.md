# iMac 21.5" Late 2013 → установка WristPlayer: пошагово

Ваш Mac: **iMac 21.5" Late 2013** (iMac14,3; Core i5, GeForce GT 750M), сейчас macOS Catalina.
Путь бесплатный, займёт вечер (большая часть — ожидание загрузок и установки).

| Что | Почему так |
|---|---|
| macOS **Sequoia 15** через OpenCore Legacy Patcher | Официально iMac 2013 заканчивается на Catalina. Патчер поддерживает iMac14,3 и его видеокарту GT 750M. |
| **Xcode 26.3** — именно эта версия | Последний Xcode, который работает на Sequoia (с 26.4 Xcode требует macOS Tahoe). По данным Apple, он ставит приложения на iOS 15 и новее, то есть и на ваш iOS 27. |
| Бесплатный Apple ID | Подпись на 7 дней; продлевается повторным запуском скрипта (шаг 5). |

## 0. Проверка Mac — ✅ пройдена
8 ГБ памяти и 100 ГБ свободно — достаточно. Если у Mac обычный жёсткий диск (не SSD и не Fusion Drive),
всё будет работать, но медленно — запаситесь терпением.

## 1. Резервная копия
OpenCore Legacy Patcher меняет загрузку Mac. Сделайте копию в **Time Machine** на внешний диск.

## 2. macOS Sequoia через OpenCore Legacy Patcher

**Подготовьте:**
- флешку на **32 ГБ или больше** (на 16 ГБ Sequoia не помещается; всё с флешки сотрётся);
- **сетевой кабель (Ethernet)** до роутера: после установки Wi-Fi заработает только после патча, а патчу нужен интернет;
- выключенный **FileVault**: Системные настройки → Защита и безопасность → FileVault (если включён — «Выключить», дождаться).

### 2.1. Установить патчер (в Catalina)
1. Откройте <https://github.com/dortania/OpenCore-Legacy-Patcher/releases/latest> — это стабильная версия
   **2.5.1** (версии 3.0 с пометкой «Pre-release» не берите).
2. Скачайте **OpenCore-Patcher.pkg**, откройте, установите. В «Программах» появится **OpenCore-Patcher**.

### 2.2. Флешка-установщик
1. Вставьте флешку, запустите OpenCore-Patcher.
2. **Create macOS Installer** → **Download macOS Installer** → выберите самую новую **macOS Sequoia 15.x** (
   Tahoe 26 не выбирайте). Загрузка ~15 ГБ.
3. Когда скачается: **Select Downloaded Installer** → выберите флешку → подтвердите, что она будет стёрта.
   Запись идёт 20–40 минут. В конце патчер предложит установить OpenCore — переходите к 2.3.

### 2.3. OpenCore на диск iMac
1. В главном окне: **Build and Install OpenCore** → дождитесь сборки → **Install OpenCore**.
2. Выберите **внутренний диск iMac** (не флешку) → раздел **EFI** → подтвердите паролем Mac.
3. Готово, когда появится сообщение об успешной установке.

### 2.4. Установка Sequoia
1. Выключите iMac. Включите, **удерживая Option (⌥)**, пока не появятся значки дисков.
2. Зажмите **Control** и щёлкните **EFI Boot** (с иконкой OpenCore) — так iMac запомнит его по умолчанию.
3. В меню OpenCore выберите **Install macOS Sequoia**.
4. В установщике выберите **«Установить macOS Sequoia»** → диск **Macintosh HD** (стирать **не нужно** —
   файлы и программы сохранятся). Установка займёт 1–2 часа с несколькими перезагрузками.
   Если iMac перезагрузился и пошёл по кругу — снова Option → EFI Boot → серый значок диска.

### 2.5. Патч драйверов (обязательно)
1. После первого входа в Sequoia подключите Ethernet. OpenCore-Patcher сам предложит **Root Patch** —
   согласитесь. Если не предложил: откройте OpenCore-Patcher → **Post-Install Root Patch** → **Start Root Patching**.
2. Введите пароль, дождитесь конца, перезагрузитесь. Теперь работают видеокарта GT 750M и Wi-Fi.
3. Проверьте: меню  → Об этом Mac → **macOS Sequoia 15.6 или новее**.

### 2.6. Чтобы ничего не сломалось потом
- Системные настройки → Основные → Обновление ПО → (i) → выключите автоматическую установку обновлений macOS.
  **На Tahoe (26) не обновляйтесь** — стабильный патчер его пока не поддерживает.
- После каждого обновления Sequoia (15.x) патчер попросит повторить Root Patch — соглашайтесь.

Официальная инструкция с картинками (англ.): <https://dortania.github.io/OpenCore-Legacy-Patcher/INSTALLER.html>.

## 3. Xcode 26.3
App Store предложит слишком новый Xcode, поэтому ставим вручную:
1. Откройте <https://developer.apple.com/download/all/?q=Xcode%2026.3>, войдите своим Apple ID (бесплатно).
2. Скачайте **Xcode 26.3** (файл `.xip`), откройте двойным щелчком — распакуется Xcode.app.
   Перетащите его в «Программы».
3. Запустите Xcode, примите лицензию, в окне компонентов отметьте **iOS** и **watchOS**, дождитесь загрузки.
4. **Xcode → Settings → Accounts** → «+» → Apple ID → войдите.

## 4. Подготовка iPhone и часов
1. iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → вкл → перезагрузка → подтвердить.
2. Подключите iPhone кабелем к iMac, разблокируйте, нажмите **«Доверять»**.
3. Часы — рядом с iPhone и разблокированы.

## 5. Установка одной командой
1. Скачайте проект: <https://github.com/abc1113def/wristplayer/archive/refs/heads/main.zip> и распакуйте
   в «Загрузки».
2. Откройте **Терминал** и выполните:
   ```bash
   cd ~/Downloads/wristplayer-main
   bash scripts/mac-install.sh
   ```
3. Скрипт спросит **Team ID** (Xcode → Settings → Accounts → ваш Apple ID → строка «Personal Team»,
   10 символов), предложит Bundle ID (просто Enter), затем соберёт, подпишет и поставит приложение на iPhone.
   Если что-то не выйдет — он откроет проект в Xcode: вверху выберите схему **WristPlayer** и ваш iPhone → ▶︎.

## 6. После установки
1. iPhone: Настройки → Основные → **VPN и управление устройством** → ваш Apple ID → **Доверять**.
2. Приложение **Watch** на iPhone → **Мои часы** → прокрутите вниз → WristPlayer → **Установить**.
3. Если на часы не ставится — в Xcode выберите схему **WristPlayerWatch** и часы → ▶︎
   (на часах тоже включите Режим разработчика: Настройки → Конфиденциальность и безопасность).

Через 7 дней приложение перестанет открываться — подключите iPhone и снова выполните шаг 5.2.
