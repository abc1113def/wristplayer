# iMac 21.5" Late 2013 → установка WristPlayer: пошагово

Ваш Mac: **iMac 21.5" Late 2013** (iMac14,3; Core i5, GeForce GT 750M), сейчас macOS Catalina.
Путь бесплатный, займёт вечер (большая часть — ожидание загрузок и установки).

| Что | Почему так |
|---|---|
| macOS **Sequoia 15** через OpenCore Legacy Patcher | Официально iMac 2013 заканчивается на Catalina. Патчер поддерживает iMac14,3 и его видеокарту GT 750M. |
| **Xcode 26.3** — именно эта версия | Последний Xcode, который работает на Sequoia (с 26.4 Xcode требует macOS Tahoe). По данным Apple, он ставит приложения на iOS 15 и новее, то есть и на ваш iOS 27. |
| Бесплатный Apple ID | Подпись на 7 дней; продлевается повторным запуском скрипта (шаг 5). |

## 0. Проверьте две вещи (2 минуты)
Меню  → **Об этом Mac**:
- **Память** — нужно **8 ГБ** (у этой модели память не расширяется; с 4 ГБ Xcode практически непригоден);
- **свободное место**: Об этом Mac → Хранилище — нужно **60 ГБ свободно**.

Если у Mac обычный жёсткий диск (не SSD и не Fusion Drive), всё будет работать, но медленно — запаситесь терпением.

## 1. Резервная копия
OpenCore Legacy Patcher меняет загрузку Mac. Сделайте копию в **Time Machine** на внешний диск.

## 2. macOS Sequoia через OpenCore Legacy Patcher
Нужна флешка на **16 ГБ+** (её содержимое сотрётся).
1. На iMac (прямо в Catalina) скачайте **OpenCore-Patcher-GUI.app.pkg** из
   <https://github.com/dortania/OpenCore-Legacy-Patcher/releases/latest> и установите.
2. Откройте **OpenCore Legacy Patcher** → **Create macOS Installer** → **Download macOS Installer** →
   выберите **macOS Sequoia 15.x** (самую новую 15-ю) → дождитесь загрузки → запишите на флешку.
3. В главном окне → **Build and Install OpenCore** → установите на **внутренний диск** iMac.
4. Перезагрузите iMac, **удерживая Option (⌥)**. Выберите **EFI Boot**, затем установщик macOS на флешке.
   Установите Sequoia поверх Catalina (программы и файлы сохраняются).
5. После первого входа OpenCore Legacy Patcher предложит **Post-Install Root Patch** — согласитесь
   (это драйверы видеокарты GT 750M), перезагрузитесь.
6. Проверьте: меню  → Об этом Mac → должно быть **macOS Sequoia 15.6 или новее**. Если меньше —
   Системные настройки → Основные → Обновление ПО.

Официальная инструкция патчера (с картинками): <https://dortania.github.io/OpenCore-Legacy-Patcher/INSTALLER.html>.

## 3. Xcode 26.3
App Store предложит слишком новый Xcode, поэтому ставим вручную:
1. Откройте <https://developer.apple.com/download/all/?q=Xcode%2026.3>, войдите своим Apple ID (бесплатно).
2. Скачайте **Xcode 26.3** (файл `.xip`), откройте двойным щелчком — распакуется Xcode.app.
   Перетащите его в «Программы».
3. Запустите Xcode, примите лицензию, в окне компонентов отметьте **iOS** и **watchOS**, дождитесь загрузки.
4. **Xcode → Settings → Accounts** → «+» → Apple ID → войдите.

## 4. Подготовка iPhone и часов
1. iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → вкл → перезагрузка → подтвердить.
2. Подключите iPhone кабелем к iMac, разблокируйте, нажмите **«Доверять»**.
3. Часы — рядом с iPhone и разблокированы.

## 5. Установка одной командой
1. Скачайте проект: <https://github.com/abc1113def/wristplayer/archive/refs/heads/main.zip> и распакуйте
   в «Загрузки».
2. Откройте **Терминал** и выполните:
   ```bash
   cd ~/Downloads/wristplayer-main
   bash scripts/mac-install.sh
   ```
3. Скрипт спросит **Team ID** (Xcode → Settings → Accounts → ваш Apple ID → строка «Personal Team»,
   10 символов), предложит Bundle ID (просто Enter), затем соберёт, подпишет и поставит приложение на iPhone.
   Если что-то не выйдет — он откроет проект в Xcode: вверху выберите схему **WristPlayer** и ваш iPhone → ▶︎.

## 6. После установки
1. iPhone: Настройки → Основные → **VPN и управление устройством** → ваш Apple ID → **Доверять**.
2. Приложение **Watch** на iPhone → **Мои часы** → прокрутите вниз → WristPlayer → **Установить**.
3. Если на часы не ставится — в Xcode выберите схему **WristPlayerWatch** и часы → ▶︎
   (на часах тоже включите Режим разработчика: Настройки → Конфиденциальность и безопасность).

Через 7 дней приложение перестанет открываться — подключите iPhone и снова выполните шаг 5.2.
