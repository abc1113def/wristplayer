# Старый Mac → установка WristPlayer: пошагово

Это бесплатный путь, но долгий (вечер-два) и с риском, что на последнем шаге не получится.
Прочитайте раздел «Риски» до начала.

## 0. Сначала проверьте Mac (5 минут)
Меню  → **Об этом Mac**. Запишите:
- **модель и год** — например, «MacBook Pro (13-inch, Mid 2012)»;
- **память** — нужно **8 ГБ или больше** (с 4 ГБ Xcode практически непригоден);
- **macOS** — какая стоит сейчас;
- свободное место: меню  → Об этом Mac → Ещё… → Хранилище — нужно **60 ГБ свободно**.

Если памяти 4 ГБ или места меньше 60 ГБ — этот путь лучше не начинать.

## Риски
- На Mac 2012 года новее всего можно поставить **macOS Sequoia 15** (через OpenCore Legacy Patcher),
  а на ней — **Xcode 26**. Телефон и часы у вас на **27-й** версии; официально Xcode 26 на них не ставит,
  это работает только с обходными приёмами. Может не получиться — тогда останется TestFlight.
- Бесплатная подпись живёт **7 дней** — потом нужно повторить шаг 5 (одна команда).
- OpenCore Legacy Patcher меняет загрузку Mac. Перед началом сделайте резервную копию (Time Machine).

## 1. macOS Sequoia через OpenCore Legacy Patcher
Нужна флешка на 16 ГБ+ (её содержимое сотрётся).
1. На Mac скачайте **OpenCore-Patcher-GUI.app.pkg** из
   <https://github.com/dortania/OpenCore-Legacy-Patcher/releases/latest> и установите.
2. Откройте **OpenCore Legacy Patcher** → **Create macOS Installer** → **Download macOS Installer** →
   выберите **macOS Sequoia 15.x** (последнюю) → дождитесь загрузки → запишите на флешку.
3. В главном окне → **Build and Install OpenCore** → установите на **внутренний диск** Mac.
4. Перезагрузите Mac, **удерживая Option (⌥)**. Выберите **EFI Boot**, затем установщик macOS на флешке.
   Установите Sequoia поверх текущей системы (данные сохраняются, но копия всё равно нужна).
5. После первого входа OpenCore Legacy Patcher предложит **Post-Install Root Patch** — согласитесь
   (это драйверы графики и Wi-Fi), перезагрузитесь.

Подробная официальная инструкция: <https://dortania.github.io/OpenCore-Legacy-Patcher/INSTALLER.html>.

## 2. Xcode 26
Xcode из App Store может оказаться новее, чем нужно для Sequoia. Поэтому:
1. Откройте <https://developer.apple.com/download/all/?q=Xcode%2026>, войдите со своим Apple ID (бесплатно).
2. Скачайте последнюю **Xcode 26.x** (файл `.xip`, ~3 ГБ), откройте двойным щелчком — получится Xcode.app.
   Перетащите его в «Программы».
3. Запустите Xcode, примите лицензию, в окне компонентов отметьте **iOS** и **watchOS**.
4. **Xcode → Settings → Accounts** → «+» → Apple ID → войдите.

## 3. Подготовка iPhone и часов
1. iPhone: Настройки → Конфиденциальность и безопасность → **Режим разработчика** → вкл → перезагрузка → подтвердить.
2. Подключите iPhone кабелем к Mac, разблокируйте, нажмите **«Доверять»**.
3. Часы должны быть рядом с iPhone и разблокированы.

## 4. Скачать проект
Скачайте <https://github.com/abc1113def/wristplayer/archive/refs/heads/main.zip> и распакуйте
(например, в «Загрузки»).

## 5. Установка одной командой
Откройте **Терминал** и выполните (путь поправьте, если распаковали в другое место):
```bash
cd ~/Downloads/wristplayer-main
bash scripts/mac-install.sh
```
Скрипт спросит **Team ID** (Xcode → Settings → Accounts → ваш Apple ID → строка «Personal Team», 10 символов),
предложит Bundle ID (просто Enter), соберёт, подпишет и поставит приложение на iPhone.
Если что-то не выйдет — он откроет проект в Xcode: вверху выберите схему **WristPlayer** и ваш iPhone → ▶︎.

## 6. После установки
1. iPhone: Настройки → Основные → **VPN и управление устройством** → ваш Apple ID → **Доверять**.
2. Приложение **Watch** на iPhone → **Мои часы** → прокрутите вниз → WristPlayer → **Установить**.
3. Если на часы не ставится — в Xcode выберите схему **WristPlayerWatch** и часы → ▶︎.

## Если на шаге 5 ошибка «iOS 27 не поддерживается»
Это то самое ограничение Xcode 26. Пришлите мне текст ошибки — попробую обходной путь.
Если не выйдет, остаётся TestFlight (docs/INSTALL.md, вариант A).
