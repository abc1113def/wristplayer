# WristPlayer

Офлайн-плеер для Apple Watch в паре с iPhone. В приложение на телефоне загружаются аудиофайлы,
часы скачивают их через Bluetooth/Wi-Fi и играют **без интернета и без телефона рядом**.

- **iPhone**: импорт MP3/M4A/AAC/WAV/AIFF/FLAC (кнопка «+», «Поделиться» из других приложений, папка
  WristPlayer в «Файлах», Apple Devices/iTunes на Windows), теги и обложки, поиск, сортировка,
  прослушивание на телефоне, тумблер «на часах» у каждой песни, прогресс передачи, место на часах.
- **Apple Watch**: список песен, «Исполняется» с перемоткой вперёд/назад, перемешивание, повтор (всё/одна),
  громкость колёсиком Digital Crown, фоновое воспроизведение через Bluetooth-наушники, управление
  из системного «Исполняется», продолжение с того же места, удаление песен прямо на часах.

Как установить на устройства — [docs/INSTALL.md](docs/INSTALL.md).

## Как это устроено

```
iPhone                                              Apple Watch
LibraryStore ── отметки «на часах» ──► PhoneSyncManager ══ WatchConnectivity ══► WatchSyncManager ──► WatchLibrary ──► AudioPlayer
                                         │  applicationContext: манифест (id песен)        │
                                         │  transferFile: аудио + метаданные + обложка      │
                                         ◄──────── applicationContext: инвентарь (что есть, место)
                                         ◄──────── transferUserInfo: удалено на часах
```

- Телефон хранит желаемый набор песен для часов и отправляет его как **манифест**. Часы удаляют всё, чего нет
  в манифесте, и отвечают **инвентарём**. Телефон досылает недостающее через `transferFile` — система передаёт
  файлы в фоне, даже когда приложения закрыты.
- Файл и манифест идут разными каналами и могут прийти в любом порядке; часы сравнивают время отправки файла
  с датой манифеста (`SyncPlanner.shouldKeepIncoming`), чтобы не удалить песню, манифест с которой ещё в пути.
- WAV/AIFF/FLAC перед отправкой перекодируются в AAC (`Transcoder`), чтобы экономить место и время.
- На часах музыка играет через `AVAudioSession` с политикой `.longFormAudio` — watchOS пускает такую музыку
  в фоне **только на Bluetooth-наушники/колонку**. Режим «Динамик часов» в настройках — экспериментальный.

## Структура

| Папка | Что внутри |
|---|---|
| `Shared/` | Общий код: модель песни, протокол синхронизации, очередь воспроизведения, демо-данные |
| `iOS/` | Приложение для iPhone |
| `Watch/` | Приложение для Apple Watch |
| `Tests/` | Unit-тесты общей логики |
| `project.yml` | Описание проекта для [XcodeGen](https://github.com/yonaskolb/XcodeGen) |
| `scripts/ci.sh` | Сборка, тесты и скриншоты в CI |
| `scripts/testflight.sh` | Подпись и загрузка в TestFlight |

## Сборка

На Mac с Xcode 26+:

```bash
brew install xcodegen
xcodegen generate
open WristPlayer.xcodeproj
```

Без Mac: каждый push в `main` собирает оба приложения и гоняет тесты на GitHub Actions
(`.github/workflows/build.yml`). Запуск вручную с флажком «скриншоты» снимает экраны демо-режима
в симуляторах iPhone и Apple Watch (артефакт `wristplayer-ci`).

Демо-режим: запуск с аргументом `-demo` (на часах дополнительно `-demoScreen nowPlaying|settings`).
